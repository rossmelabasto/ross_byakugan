# Byakugan — Términos y condiciones (versión 1)

Byakugan es un asistente de estudio: responde preguntas con la opción correcta y una explicación breve para ayudarte a repasar y practicar.

1. **Uso responsable.** Eres el único responsable de cómo uses las respuestas. Respeta el reglamento de tu institución; Byakugan no está pensado para vulnerarlo y no se hace responsable de sanciones académicas.
2. **Acceso por invitación.** Tu código es personal e intransferible. Puede ser revocado en cualquier momento.
3. **Qué se guarda.** Por cada consulta se registran el texto enviado, la respuesta, la fecha, tu dispositivo (fabricante, modelo, versión de Android) y el alias asignado. También cuándo fue la última vez que la app estuvo activa.
4. **Para qué se usa.** Solo para operar el servicio, controlar cuotas, detectar abusos y mejorar las respuestas. No se vende ni se comparte con terceros, salvo el proveedor del modelo (Groq), que procesa el texto para responder.
5. **No envíes datos sensibles** (contraseñas, documentos de identidad, información de terceros).
6. **Exactitud.** Las respuestas las genera una IA y pueden estar equivocadas. Verifica lo importante.
7. **Cuotas y cambios.** Hay un límite diario de consultas según tu plan. El servicio puede cambiar, pausarse o terminar sin aviso previo.
8. **Borrado.** Puedes pedir que se eliminen tu dispositivo y tu historial escribiendo a quien te invitó.

Al aceptar confirmas que leíste y estás de acuerdo con estos puntos.
